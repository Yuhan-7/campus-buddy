# 校园搭子匹配系统 · Vue + Spring Boot + MySQL + Docker

这个目录是独立于原 Python 版的新版本。页面由 Vue 3 + Vite 构建，API 使用 Spring Boot，所有账号和需求集中保存在 MySQL，Docker Compose 启动三项服务。Redis 暂未加入：当前规则式推荐和数据量不需要缓存，避免增加单人项目的部署负担。

## 不用 Docker，直接在 Mac 上运行

本目录附有 `campus-buddy-local.jar` 和 `启动-免Docker.command`。Mac 需要 Java 21。打开终端，在本目录运行 `sh 启动-免Docker.command`，然后访问 `http://localhost:8088/`。Windows 可双击 `启动-免Docker-Windows.bat`。这个模式使用本地 H2 数据库，数据保存在 `data/`，与 Docker/MySQL 的数据库互不共享。关闭终端即停止服务。

## Docker 本机运行

1. 安装并启动 Docker Desktop。
2. 将 `.env.example` 复制为 `.env`，替换其中两个密码。
3. 在本目录运行 `docker compose up --build -d`。
4. 浏览器访问 `http://localhost:8088`（或 `.env` 中指定的端口）。
5. 查看状态：`docker compose ps`；查看日志：`docker compose logs -f`；停止：`docker compose down`。

也可以在本目录运行 `sh 更新并检查网站.command`，它会重建容器并等待 `/api/health` 返回正常。网页能打开但无法登录时，先查看该健康地址；如果显示 502，说明前端已启动但后端没有运行。

首次启动会建立空数据库，没有公开演示账号。每位用户自行注册。数据库放在 Docker 卷 `mysql_data` 中，普通 `docker compose down` 不会删除数据；`docker compose down -v` 会删除数据，请勿用于日常停止。

## 功能

邮箱格式校验后注册；使用邮箱或账号 ID 登录，账号 ID 为注册日期加六位随机序列，昵称不能重复。登录后可设置 3 个密保问题，忘记密码时答对任意 2 个可重置，连续失败 5 次会暂时锁定 15 分钟。尚未设置密保问题的账号无法通过密保找回密码，应尽快登录设置。其余功能包括公开个人资料及私有联系方式、需求发布、匹配推荐、邀请处理，以及双方同意后查看联系方式。浏览器页面通过同源 `/api` 访问后端。

管理员邮箱由 `.env` 中的 `ADMIN_EMAIL` 指定。首次启动时，如果该邮箱已经注册，会把现有账号设为管理员，并将密码同步为 `.env` 中的 `ADMIN_PASSWORD`；如果尚未注册，则创建管理员账号。此初始化只执行一次，之后重启不会覆盖在网站中修改的密码。登录后在“管理端”查看最多 500 条用户、需求与匹配成功记录，可停用或恢复普通账号、撤下需求帖子、给发布者发送站内私信。管理员只查看公开资料，不查看联系方式。`.env` 不要发送给他人。

需求详情页按账号和日期记录浏览，同一账号每天打开同一帖子只计一次。需求广场显示帖子浏览量与近 7 天的热门搭子主题，主题由需求标签和标题中的“……搭子”提取；点击主题会搜索相关需求。用户可关闭、重新开放或删除自己的需求；删除会撤回待处理邀请，已同意的匹配记录仍保留。站内信在顶部“站内信”页面查看。被管理员撤下的帖子不再公开，作者也不能自行重新开放。管理员只看公开资料，通过站内信联系发布者，用户的联系方式仍只在双方同意邀请后向参与者开放。访问 `http://localhost:8088/api/health` 可检查后端是否正在运行。

## 与旧版数据

此版本使用全新 MySQL 数据库，不会自动读取原 Python 版的 `data.sqlite3`。不要把原数据库放进公开仓库或镜像。需要保留旧账号时，应另做一次性迁移并处理密码哈希算法差异。

## 公开部署前

当前配置用于本机或可信网络演示。若向互联网开放，需要域名和 HTTPS 反向代理、邮箱所有权验证、登录与注册限流、隐私告知与数据删除机制、备份与恢复流程，并检查网络与服务器访问控制。不要把 8088 的 HTTP 服务直接暴露到公网。注册邮箱目前只是账号名，不发送验证邮件，也不能证明是本校学生。
