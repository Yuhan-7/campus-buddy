# 揭榜任务 2：视障友好适配（Windows 桌面版）

## 一、适配形式

- 新增 `desktop/`：用 Electron 把原网页包装成 Windows 桌面程序“校园搭子”。界面、业务逻辑和后端都没有变，桌面版只是一个窗口外壳。
- Electron 的界面由 Chromium 渲染，讲述人 / NVDA 读取的是网页的无障碍树（控件名称、角色、状态），所以主要适配工作在 `frontend/src/App.vue` 和 `style.css` 里完成，网页版也同时受益。
- **没有新增业务功能**，只修改可访问性相关的标签、焦点和样式。

## 二、对照《Windows 应用无障碍可访问性开发指南》的四项要求

| 指南要求 | 本项目的做法 | 位置 |
|---|---|---|
| 1. 控件有可读的名称、角色和状态 | 卡片里重复的“查看详情 / 查看资料 / 发送邀请 / 同意 / 拒绝 / 删除”等按钮加上带对象的名称（如“同意 张三 的邀请：周六羽毛球”）；切换按钮用 `aria-pressed` 读出“已按下”；展开联系方式用 `aria-expanded`；登录/注册切换改为切换按钮组（原 tab 角色不支持方向键，会误导读屏用户）；装饰符号 ✎◉✦ 对读屏隐藏；时间段“14:00–16:00”改为“14:00 到 16:00”，避免读成“减”；隐私说明表格加标题 | App.vue |
| 2. 全部功能可用键盘完成，焦点清晰 | 弹窗打开时焦点进入弹窗，Tab 在弹窗内循环，Esc 关闭，关闭后焦点回到原按钮；弹窗打开时背景设为 `inert`；切换页面后焦点移到新页面标题并更新窗口标题；拒绝邀请时焦点进入原因输入框，取消后回到“拒绝”按钮；撤销关闭需求可用 Alt+Z；桌面版提供中文菜单（Alt 进入）和 F1 键盘说明 | App.vue、desktop/main.js |
| 3. 支持系统高对比度 | 新增 `@media (forced-colors: active)`：Windows“对比度主题”下保留边框、焦点框（Highlight 色）、当前页面/已按下状态和禁用状态；页面自带的“高对比”模式焦点框加粗加黄色外圈；尊重“减少动画”设置 | style.css |
| 4. 无障碍模式下功能完整 | 提示信息改为常驻播报区域：普通提示礼貌播报，错误立即播报，同一句话重复出现也会再读；两次密码不一致的错误与输入框关联（`aria-invalid` + `aria-describedby`）；加载中设置 `aria-busy`；后端未启动时显示可读的说明页和“重试”按钮，而不是空白窗口 | App.vue、desktop/offline.html |

## 三、运行方法

1. 在项目根目录启动后端：`docker compose up -d`。
2. 在 Windows 里安装 Node.js（LTS 版本），进入 `desktop` 文件夹：
   ```
   npm install
   npm start
   ```
3. 如果后端运行在 Mac 上、程序运行在 Windows 虚拟机里，先设置后端地址（Parallels 下宿主机一般是 10.211.55.2，以虚拟机里实际能打开的地址为准）：
   ```
   set CAMPUS_BUDDY_URL=http://10.211.55.2:8088
   npm start
   ```
4. 打包成单个 exe（可选，在 Windows 里执行）：`npm run dist:win`，生成在 `desktop/release/`。
