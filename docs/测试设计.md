# 测试设计（对应课程第 7 章）

运行：IDEA 中右键 `backend/src/test/java` → 运行所有测试；或命令行 `cd backend && mvn test`（测试用内存 H2 数据库，不需要 MySQL）。

## 黑盒与白盒

| | 黑盒测试 | 白盒测试 |
|---|---|---|
| 依据 | 需求规格：输入什么、应该得到什么 | 代码内部结构：判断、分支、路径 |
| 方法 | 等价类划分、边界值分析、状态转换、权限与异常情况 | 分支覆盖、基本路径覆盖 |
| 本项目 | `BlackBoxTest`、`QualityRequirementTest`、`ApiFlowTest`、`InputsTest`、`AiAssistTest` | `WhiteBoxMatchTest`（配合 `MatchServiceTest`）对匹配打分做分支与路径覆盖 |

另有 `DemoDataTest` 检查演示数据可用（冒烟测试）。

## 黑盒：等价类与边界值示例

| 输入 | 有效等价类 | 无效等价类 | 边界值用例 | 用例 |
|---|---|---|---|---|
| 注册密码长度 | 8–20 位 | < 8 位、> 20 位 | 7 / 8 / 20 / 21 位 | TC-01 |
| 需求标题长度 | 3–60 字 | < 3 字、> 60 字 | 2 / 3 / 60 / 61 字 | TC-02 |
| 年龄 | 16–100 或不填 | < 16、> 100、非数字 | 15 / 16 / 101 | TC-03 |
| QQ 号 | 5–15 位数字或不填 | 少于 5 位、含字母 | 4 位 / 5 位 | TC-03 |
| 拒绝原因 | 0–100 字 | > 100 字 | 101 字 | QR-F4 |
| 时间段 | 同一天、结束晚于开始、≤ 12 小时 | 结束早于开始、> 12 小时、星期非法 | 13 小时 | QR-R3 |

## 白盒：匹配打分的判断点与覆盖

`MatchService.score` 判断点：D1 共同时间是否为 0；D2 共同兴趣是否为空；D3 主题契合是否为空；D4 技能互补是否为空；D5/D6 兴趣并集、需求标签是否为空（防止除以 0）。`overlapMinutes` 判断点：E1 是否同一天；E2 时间格式是否合法。

| 用例 | 覆盖的路径 / 分支 |
|---|---|
| QR-M1 | D1 真（无共同时间，直接不推荐） |
| WB-1 | D1 假，D2/D3/D4 全假，D5/D6 为空集 |
| WB-2 | D2 真，D3/D4 假 |
| WB-3 | D3 真，D2/D4 假 |
| QR-M4 | D4 真，D2/D3 假 |
| QR-M2 | D2/D3/D4 全真（满分 100） |
| WB-4 | E1 假；多条需求取最大重叠 |
| QR-R1 | E2 假（脏数据跳过） |
| WB-5 | 时间分封顶边界 |

| 测试类 | 数量 | 类型 | 内容 |

| DemoDataTest | 1 | 冒烟 | 演示数据可用 |
| **合计** | **43** | | |

不需要启动 Spring 的 18 个单元测试（InputsTest、AiAssistTest、MatchServiceTest、WhiteBoxMatchTest）运行很快，修改匹配规则后可先单独运行它们做回归测试。

## 未自动化的部分（手工检查）

前端界面暂无自动化测试，以下靠手工检查：大字 / 高对比模式、断网提示、关闭需求后 8 秒内可撤销、密码“小眼睛”、注册两次密码不一致的提示、拒绝原因表单。
