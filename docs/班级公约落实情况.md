# 班级软件开发行为公约 · 落实情况

本项目为个人项目，以下逐条说明公约在代码中的落实位置。未做到或有意放弃的部分也如实列出（公约第六条）。

| 条款 | 落实方式 | 代码位置 |
|---|---|---|
| 第三条 数据采集须说明用途 | 注册时必须勾选同意《个人信息使用说明》；说明内容由后端 `/api/privacy` 返回，逐项列出“采集什么、用途、谁能看到”，前端直接展示这份清单，避免文案与实际行为不一致；资料页注明哪些字段可不填、联系方式的可见范围。同意记录写入 `privacy_consents` 表。 | `auth/PrivacyController.java`、`auth/AuthController.register`、`App.vue` 注册表单与说明弹窗 |
| 第四条 发现设计隐患须及时提出 | 重构时发现并修复：① 需求广场先 `LIMIT 200` 再在内存中筛选，数据多时会漏掉结果；② 开始时间较晚时“时长”会算出 24:00 之后的结束时间，被后端拒绝但提示不清；③ 推荐接口每个候选人查一次数据库（N+1）。暂未解决的隐患写在 README“公开部署前”一节。 | 见 git 提交记录 |
| 第五条 高危操作二次确认，可恢复操作优先撤销 | 不可逆：删除需求、拒绝邀请、撤回邀请、管理员停用账号/撤下帖子 → 确认框；注销账号 → 确认框 + 输入密码 + 输入“确认注销”。可恢复：关闭需求 → 提示条中提供“撤销”。 | `App.vue` 中 `deleteNeed`、`handleInvitation`、`adminUserAction`、`adminRemoveNeed`、`deleteAccount`、`toggleNeed/reopenNeed` |
| 第六条 不伪造、不隐瞒 | 测试结果、工作清单数据均来自仓库实际统计；未能在开发环境运行的测试在工作清单中单独注明。 | `docs/质量需求与测试对照.md` |
| 第七条 视障/老年用户基础适配 | 顶栏“大字”“高对比”开关（记住选择）；浅灰文字对比度提升到 4.5:1 以上；键盘焦点高亮、“跳到主要内容”链接；弹窗 `role=dialog`、可按 Esc 关闭；提示信息 `aria-live`；所有输入框有可读标签；尊重系统“减少动态效果”设置。 | `style.css` 末尾 v1.2 段、`App.vue` 顶栏 |
| 第八条 交付前基础整理 | 邀请状态（pending/accepted…）、需求状态改为中文；时间统一显示到分钟；错误提示改为可操作的说明（如“请先在个人资料中填写至少一种联系方式”）。 | `format.js` |
| 第九条 核心功能免注册体验 | 需求广场、需求详情、热门主题无需登录即可浏览；发布、查看个人资料、邀请等涉及他人信息的操作才要求登录。访客查看详情不计入浏览量。 | `need/NeedController.java`、`SessionService.optionalUser` |
| 第十条 交付前整理代码结构 | 原 113 行、单行最长约 2000 字符的 `ApiController` 拆为 `common / auth / profile / need / match / invitation / admin` 7 个包；匹配打分抽为纯函数 `MatchService` 并单独单元测试；前端拆出 `api.js`、`format.js`，模板改为多行可读结构。 | `backend/src/main/java/com/campusbuddies/` |
| 第十一条 为不增加用户负担而放弃功能 | 放弃：注册邮箱验证码（需邮件服务，增加注册步骤）；Redis 缓存（数据量小，增加部署负担）；站内即时聊天（超出范围，且会让联系方式外的信息留在平台）；手机号实名（隐私敏感用户负担大）。 | README“功能取舍” |

## 第十三条 特殊用户群体检查表

| 用户群体 | 风险 | 处理 |
|---|---|---|
| 老年用户（操作困难） | 按钮小、流程长 | 大字模式；关键操作有中文说明；注册只需邮箱和密码 |
| 视障 / 色弱 / 色盲用户 | 文字对比度低、仅靠颜色区分 | 高对比度模式；对比度提升；状态均有文字（不只靠颜色）；读屏可用的标签与 aria 属性 |
| 低配手机用户 | 一次渲染卡片过多导致卡顿 | 广场每页 24 条 + “加载更多”；搜索防抖 300ms；无大图、无第三方 UI 库 |
| 经济困难用户 | 付费门槛 | 全部功能免费，无付费项；说明中明确“本系统不收费” |
| 隐私敏感用户 | 个人信息被他人或平台过度获取 | 资料全部选填；联系方式仅双方同意后可见，管理员也不可见；可随时注销并清除资料 |
| 无稳定网络用户 | 请求挂起、重复提交 | 请求 15 秒超时并提示；断网横幅；提交中按钮禁用防止重复提交 |
